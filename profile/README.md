# Ziora Security

Ziora is a desktop app for security code review, for Windows, macOS and Linux.

- Maps every route, webhook and deep link, and the guard in front of each one
- Runs 70+ built-in checks plus Semgrep, gitleaks and OSV-Scanner, merged into one list
- Writes a fix plan for your AI coding agent and checks the fixes afterwards
- Runs on your computer. No telemetry, no account.

Free during the public beta: [ziorasecurity.com](https://ziorasecurity.com)

Found a security issue? Email security@ziorasecurity.com.
